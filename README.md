# Watson

A writing sidekick — the one who turns your messy brilliance into something legible.

Watson is named after the classic partner role: you bring the ideas; Watson helps with structure, tone, clarity, and polish.

## Status

Early scaffold. API and UI coming soon.

## Ideas

- Draft from bullet notes or voice
- Tone presets (casual, professional, punchy)
- Rewrite selection: shorter, clearer, warmer
- Outline → sections → full draft
